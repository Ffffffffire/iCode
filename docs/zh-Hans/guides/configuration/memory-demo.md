# 个人记忆演示

本演示用虚构的“橙桥检查”和“石杉项目”，体验一条经验如何影响后续建议、如何更正，以及何时停止使用。模型的回答可以不同；需要核对的是保存内容、适用条件、来源和实际使用方式。

启动 iCode，选用已配置、支持工具调用的模型。输入 `/memory`，选择 **自动召回** 和 **明确要求才保存**。示例会保存到当前记忆库；完成后可以按最后一步移除。新会话请使用 `/new`，它会保留原会话。

## 1. 先看没有这条记忆时的回答

在新会话发送：

> 我准备把评审流程改成自动发布，请给一个决策建议。

保留这次回答。如果库中已经有类似经验，先停用，或将调用方式改为 **关闭记忆**。后面的比较重点是有没有沿用你保存的判断顺序，普通的灰度发布建议本身不能证明记忆有效。

## 2. 用一句话保存一个有条件的判断方法

将调用方式恢复为 **自动召回**，发送：

> 请帮我记住：跨项目给我做评审决策时，用橙桥检查：先指出会推翻建议的证据，再给可逆的小实验，最后才建议扩大投入。如果只是润色文字就不要套用。

打开 `/memory`。预期在 **已记住** 看到一条简短记忆，范围是 **跨项目**，并保留判断顺序和“仅润色文字不适用”的条件。展开来源应能找到刚才的原话。它不应先进入待确认队列，也不应要求你再次批准同一次明确保存。

如果助手声称已保存，但列表中没有记录，这一步没有完成。可以直接点 **+ 记一条**，填写内容后取消 **仅当前项目**；自然语言保存失败仍应单独记录。

## 3. 在全新会话中观察记忆发挥作用

执行 `/new`，再次发送第一步的原问题，不提“记忆”或“橙桥”。

预期建议先讨论可能推翻方案的证据，再提出可逆小实验，最后谈扩大投入。底部的 **参考** 入口可以打开 **本轮参考**；选中记忆，展开 **为什么提供这条记忆** 检查匹配依据。回答应能让你知道橙桥检查来自过去保存的偏好。

这里有两件不同的事：**本轮参考** 证明内容提供给了模型；回答采用了这个顺序，才表明它实际影响了建议。普通建议中碰巧出现“小实验”并不足以证明第二件事。

## 4. 让当前要求优先

执行 `/new`，发送：

> 我准备把评审流程改成自动发布。这一轮只写一句发布公告，不要给决策建议。

预期只得到公告，不强行展开橙桥三步；保存的记忆仍然保留原样。**本轮参考** 仍可能出现它，因为检索按词项匹配，是否适用于当前任务还需要模型判断。

## 5. 更正原条目

发送：

> 请帮我更新这条记忆：橙桥检查的新顺序是先做可逆的小实验，再指出会推翻建议的证据，最后才建议扩大投入。适用范围仍是跨项目的评审决策；只润色文字时仍不要套用。

在 `/memory` 检查：仍是一条橙桥记忆，版本递增，历史版本保留旧顺序，范围和例外条件未丢失。再 `/new` 并发送第一步的问题，回答应使用新顺序。旧建议不应作为另一条有效记忆并存。

如果助手不知道该修改哪条，先定位原条目；也可以直接选中它点 **编辑**。不要用不断新增的方式纠正同一条事实。

## 6. 区分个人与项目

在一个演示目录内发送：

> 请记住：当前石杉项目的发布核对清单名称是杉叶47，仅在本项目发布核对时使用，项目结束就停止使用。

确认它为 **仅当前项目**。同目录 `/new` 后问“石杉项目的发布核对清单叫什么？”，应能答出“杉叶47”。再用 `/chdir` 切到另一个演示目录，执行 `/new` 后问相同问题：这条记忆不应被提供，也不应凭空知道清单名称。跨项目的橙桥记忆仍可在相关问题中使用。

在另一个目录打开 **全部** 仍能管理项目条目；“可管理”与“当前项目可召回”是不同的边界。

## 7. 体验可控的提炼与停止使用

| 操作 | 输入或动作 | 应当看到 |
| --- | --- | --- |
| 自动偏好 | 选择 **自动记住明确偏好**；发送“做技术 PPT 时，我更喜欢图文结合、信息密度较高的版面，架构和模型原理尽量画成图。” | 提炼后提示 **已记住**，条目直接在 **已记住** 中，无需再说“记住” |
| 自然纠正 | 发送“以后技术 PPT 还是图文结合，但信息密度改成适中，别默认高密度。” | 更新原条目并保留旧版本；不追加一条相反偏好 |
| 请求候选 | 选择 **全部先确认**；发送“我们反复试过，给北窗项目写运行指南时，以可复制的命令开头比先铺背景更有效。请从这句话提出一条待我确认的项目记忆建议，先不要正式启用。” | **待确认** 显示来源；点击 **记住** 前不参与后续召回 |
| 明确不保存 | 发送“不要记住：这次报告只是临时采用蓝色。” | 不增加有效条目，也不增加候选 |
| 按需使用 | 切到 **按需召回**，新会话发送第一步问题，再明确说“请查一下个人记忆再回答” | 第一次不自动提供；明确查询后可出现参考 |
| 暂停一条 | 选择橙桥记忆点 **停用**，新会话发送第一步问题 | 橙桥不再进入本轮参考；可在 **已停用** 中恢复 |
| 全部停止调用 | 选择 **关闭记忆**，新会话发送第一步问题 | 不提供任何个人记忆；库中内容仍可管理 |

关闭的是调用和候选提炼；主动在编辑器保存、或明确请求保存仍属于用户的直接操作。更改调用模式后用新回合观察；关掉记忆不会抹掉当前聊天中已经出现的文字。

## 8. 结束演示

在 `/memory` 中找到“橙桥”“杉叶47”“北窗”等演示条目，逐条 **忘记** 并确认。检查已保存、待确认和已停用视图，再恢复你想使用的调用模式。历史聊天仍然保留；新会话中不应再从记忆库找回已忘记的内容。

适用边界、长度限制、修订历史及参考文件用法见[配置记忆](memory.md)。
